💇 Hair Salon Management System

📌 Overview

Hair Salon Management System is a web application designed to simplify the daily operations of hair and barber salons.
Built with ASP.NET Core MVC, it provides an efficient way to manage services, staff schedules, and customer appointments.
With integrated AI features, users can even get hairstyle and color suggestions based on uploaded photos.

🚀 Features
🏢 Salon Management

Define salon working hours, services, service durations, and pricing.

Support for single or mixed salons (male/female).

👨‍💼 Staff Management

Define staff expertise and working hours.

Allow appointment booking based on staff availability.

📅 Appointment System

Customers can select services and book available staff.

Automatic appointment conflict detection.

Appointment details stored and confirmed.

🔗 REST API Integration

Database communication through REST APIs.

Advanced data querying & filtering using LINQ.

🤖 AI Integration

Upload photos to receive AI-powered hairstyle and color suggestions.

⚙️ Technologies Used

Back-End: ASP.NET Core 6 MVC, C#

Front-End: HTML5, CSS3, Bootstrap, JavaScript, JQuery

Database: SQL Server or PostgreSQL (via Entity Framework Core ORM)

API Communication: REST API

Artificial Intelligence: Hairstyle & color suggestion engine
